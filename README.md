# rclear

This is a reimplementation of the clear command but with a built in slot 
machine. To win, match at least two which will clear the screen. Otherwise no 
dice!

## Install
Download the prebuilt binaries from the release section for your platform then
add to your path.

## Development
### Run from source

```bash
bun install
```

To run:

```bash
bun run index.ts
```
